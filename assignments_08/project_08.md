For this project, I used the Azure Pricing Calculator to compare the cost of two different cloud setups. The first scenario used a small virtual machine for light work during business hours, and it was very affordable, costing only a small amount each month. The second scenario included a powerful GPU virtual machine, an Azure SQL Database, and 1 TB of storage running all month, which made the cost much higher. What surprised me the most was how expensive GPU and database services are compared to storage. This project helped me understand how cloud computing costs can change depending on the type of resources and how long they run.
